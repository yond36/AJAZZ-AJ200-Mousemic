## v1.5.0 — 侧键滚轮音量与托盘交互

### 新功能与界面
- 前进键、后退键新增“按住加滚轮调音量”：按住所选侧键，上滚增大、下滚减小系统音量。各键独立配置，音量用途与同键语音/联动热键/短按模式互斥，另一键仍可用于语音。旧配置默认关闭新功能。
- 普通侧键点击在松开时补发；组合滚动期间拦截页面滚动。停止桥接卸载监听，断连清空按住状态和旧操作。音量组合对所有连接的鼠标生效。
- “Typeless”界面文字改为“短按模式”。托盘图标单击切换主窗口显示/隐藏，右键菜单保留。
- 选择 Interception 后，启动桥接前检查程序目录的 interception.dll；缺少时弹窗提示具体路径并取消启动。

### 修复与精简
- AI 配置优先使用握手成功的命令通道，采用与握手一致的64字节报告；混合用途明确禁用另一键的 AI 状态。
- AI 配置写入失败时保留已连接的音频链路并明确记录错误，不再将其误报为未找到鼠标接口。
- 移除无 GUI 命令行模式、WAV 录音入口及专用依赖；仅保留图形应用与开机自启参数 --autostart。
- 移除本次排查增加的输入时序日志、Raw Input 诊断监听和队列，保留原有调试日志。

### 使用注意
- 实机记录中存在滚轮先于侧键按下事件到达 Windows 的情况：这段期间滚轮仍正常滚动。为保持普通滚轮即时响应，本版不添加缓冲延迟。请先按住侧键稍停再滚动；本版不宣称消除设备输入上报时差。
- 音量功能随桥接服务启停，仍需连接鼠标并成功初始化音频输出。单击回放使用 SendInput，权限较高的应用可能拒绝输入。
- 升级前退出旧程序，将新版 exe 放到原目录，保留 mousemic_gui.json。运行中修改按键用途需停止后重新启动桥接。
