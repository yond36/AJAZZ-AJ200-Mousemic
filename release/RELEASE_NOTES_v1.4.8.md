## v1.4.8 — 原生界面优化

### 界面与布局
- 主窗口调整为 920×680 的紧凑双栏布局：顶部集中显示运行状态和启动/停止操作，左侧为音频与按键设置，右侧为环境自检和启动选项，底部为日志。
- 统一浅灰背景、白色分区与蓝色主按钮；中文系统字体按标题、分组和辅助信息分级，优化控件间距和长选项显示。
- 保留 Win32 原生控件、键盘导航和焦点反馈；系统高对比度模式回退原生样式。

### 设置与状态反馈
- 输出设备、前后热键、注入方式和自动发送延迟即时保存；运行中修改音频、热键和发送设置时提示下次启动桥接生效。
- 未启用自动发送时，发送方式和延迟输入自动禁用。
- 将原来的“无”明确显示为“禁用语音”，保留“仅语音(无热键)”选项及旧配置兼容性。
- “刷新音频设备”同时更新设备下拉框并保留当前选择。
- 增加启动中的状态提示，初始化停止按钮与托盘菜单的启用状态；停止后清除过期电量。
- 明确 VB-CABLE 仅虚拟麦克风模式需要，Interception 为可选组件。

### 日志
- 新增清空日志、暂停刷新和恢复自动滚动，暂停时仍在后台保留最新日志。
- 每个计时器周期批量刷新日志，减少逐条重绘。

### 验证
- 默认 GUI 特性：35 个单元测试 + 2 个黄金向量集成测试通过。
- 无 GUI 特性：29 个单元测试 + 2 个集成测试通过。
- 格式检查、Clippy 与 Windows x64 发布构建通过。
- 使用独立临时配置验证实际窗口：初始按钮状态、模式切换、自动发送联动、延迟/热键保存、设备刷新、日志暂停/恢复与清空、启动失败后状态复位、托盘隐藏和正常退出。
- 100% 缩放下未发现控件越界或单行文字截断。其他缩放比例及本次语音收音链路未重新实测。

### 下载与升级
- 下载 `MouseMic.exe`，退出旧程序后替换原 exe 即可；保留原目录中的 `mousemic_gui.json`，不需要重新配置。
- `interception.dll` 与上一版本相同，仅使用 Interception 注入方式时需要放在 exe 同目录。
- 不包含本机配置、录音或日志；本次不改动底层音频解码、HID 桥接及热键会话逻辑。
