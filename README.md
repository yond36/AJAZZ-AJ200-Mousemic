# AJAZZ AJ200 Mousemic

将 AJAZZ 语音鼠标（VID=363C）的蓝牙音频桥接为系统麦克风输入，支持语音实时播放和虚拟麦克风转发。

## 功能

- **扬声器试听模式**：鼠标语音实时通过扬声器/耳机播放
- **虚拟麦克风模式**：桥接到 VB-CABLE 虚拟输入，其他软件可选为麦克风源
- **联动热键**：按住鼠标语音键时自动模拟键盘按键，支持单键和组合键（R_alt+space、R_alt+R_shift、R_alt+R_ctrl 等）
- **仅语音模式**：前进/后退键可独立设为“仅语音”——长按直接触发麦克风，**不注入任何按键**（纯麦克风用法，无需绑定热键；GUI 热键下拉选“仅语音(无热键)”）
- **短按模式**：前进/后退键可独立启用，按住语音键=短按热键开始，松开后音频结束自动再短按热键结束
- **自动发送**：语音结束后延迟自动按 Enter 或 Ctrl+Enter
- **侧键＋滚轮调音量**：前进/后退键可独立选择“按住加滚轮调音量”，按住后上滚增大、下滚减小系统音量；与同一个键的语音功能互斥，另一键仍可用于语音
- **AI 键管理**：启动时按各键用途配置 AI，停止/退出时自动关闭
- **热插拔自动切换**：有线/无线链路自动识别、断线重连
- **电池状态显示**：顶部实时显示电量百分比与充电状态（被动上报，不增加鼠标耗电）；电量 ≤10% 或充满时托盘气泡提醒
- **设备识别（PID 白名单）**：仅识别 AJ200 系列已知 PID，检查依赖时显示识别到的鼠标型号、传感器、飞轮及 PID 信息
- **系统托盘**：运行中关闭窗口最小化到托盘，停止状态关闭即退出；支持开机自启
- **调试日志**：勾选后在下次启动桥接时输出语音包/解码/队列等详细统计
- **原生 GUI**：Win32 原生控件；紧凑双栏布局、浅色分区和蓝色主操作按钮，保留轻量桌面界面
- **设置即时保存**：输出设备、热键和发送选项自动保存；运行中修改音频/热键/发送设置后，重新启动桥接生效
- **日志查看**：支持清空日志、暂停刷新和恢复自动滚动，便于翻查与复制

## 侧键＋滚轮调音量

在界面的前进键或后退键下拉框中选择 **“按住加滚轮调音量”**，然后启动桥接；若服务正在运行，请停止后重新启动，使新设置生效。旧配置默认关闭此功能。

- 按住所选侧键并向上滚动增大系统音量，向下滚动减小音量；每格使用 Windows 默认音量步进（通常为 2%）。程序收到侧键按下后会拦截组合滚动。若设备的侧键按下事件晚于滚轮到达，之前的滚轮仍会正常滚动；使用时先按住侧键稍停再滚动。普通滚轮不增加缓冲延迟。
- 该键的语音、联动热键和 短按模式 关闭。推荐一键调音量、另一键保留“仅语音”或语音热键；也可以两键都设为调音量。同一键同时承担语音与音量手势的固件事件时序尚未验证，因此采用每键互斥。
- 只按侧键而不滚动时，松开后补发普通前进/后退点击。因此点击触发时间变为松开时，不适合依赖侧键按住或拖拽的操作。
- 此功能随桥接服务启停，目前仍需鼠标连接及音频输出初始化成功。断连时会清除按住状态和待处理动作；桥接等待重连期间，音量监听仍保持运行。
- 音量组合对电脑连接的**所有鼠标**生效，不能限定为 AJAZZ。音量及补发点击使用 Windows SendInput，不随语音热键的驱动选项切换；权限较高的应用可能拒绝补发输入。

## 系统要求

- Windows 10 / 11
- [VB-CABLE](https://vb-audio.com/Cable/index.htm)（虚拟麦克风模式需要）
- [Interception](https://github.com/oblitum/Interception)（可选，仅当模拟按键在特定程序中失效时需要）。界面选择 `interception` 后，启动桥接前会检查 `MouseMic.exe` 同目录下的 `interception.dll`；缺少时弹窗提示并取消启动，也可改选 `sendinput`。

> 注：Rust 版本需 1.82+（构建用）。

## 下载

从 [Releases](../../releases) 下载最新 `MouseMic.exe`，放到任意目录运行即可。

## 构建

```bash
# 需要 Rust 1.82+ 和 MSVC 编译工具链
git clone https://github.com/yond36/AJAZZ-AJ200-Mousemic.git
cd AJAZZ-AJ200-Mousemic
cargo build --release
```

产物：`target/release/MouseMic.exe`，双击打开 GUI。应用始终包含图形界面；开机自启由界面设置，注册表使用 `--autostart` 参数启动。图标已嵌入程序，无需额外携带图片文件。
图标源文件为 [`assets/mousemic.svg`](assets/mousemic.svg)，Windows 多尺寸图标为 [`assets/mousemic.ico`](assets/mousemic.ico)；如需调整图形，可同步编辑 SVG 和 `assets/generate_icon.py`，使用 Pillow 运行 `python assets/generate_icon.py` 重新生成 PNG 与 ICO。

## 技术细节

- **语言**：Rust（原版 Python/tkinter，Rust 版内存更低、启动更快）
- **音频解码**：mSBC（蓝牙低功耗音频编解码），基于 BlueZ sbc 库静态编译
- **HID 通信**：hidapi，音频接口 usage_page=0xFFAA；电池状态被动上报于 0xFFA0 usage=0x0002（`[0x0A,0x13,...]`，buf[17]=充电标志、buf[18]=电量%）
- **音频输出**：cpal (WASAPI)，16kHz→48kHz 线性重采样
- **热键注入**：SendInput 扫描码 / Interception 内核驱动（可选）
- **GUI**：native-windows-gui（Win32 原生控件 + GDI 系统字体）
- **托盘提醒**：Shell_NotifyIconW 气泡（NIF_INFO）
